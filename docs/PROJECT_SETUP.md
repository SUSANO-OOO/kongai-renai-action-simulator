# 開発環境

リポジトリ：https://github.com/SUSANO-OOO/kongai-renai-action-simulator

GitHub上ではPublic。コミット作者の実名メール/トークン/個人情報を含めない。別作品Zombieeeは読み取り参照のみ。

技術：Vite + TypeScript + Three.js。390x844のスマホ縦型を基準にし、Three.jsで実際の3D描画を行い、UIは編集可能なDOM/CSSで構築する。

最優先は `AGENTS.md` のART-FIRST原則と `docs/ART_FIRST_APPROVAL.md`。仮モデル・実装コードを先行完成扱いすることは禁止。WebデモのGitHub Pages公開は実機動作・ライセンス検証後に行う。
