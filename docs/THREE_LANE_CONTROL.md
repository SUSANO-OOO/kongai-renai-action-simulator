# 3レーン＋フリーレーン操作 — 正式仕様

**2レーンは不採用。** プレイヤーに「左・中央・右」の3つの進路が明確に見えるコースを用意する。ただし移動はレーン中心3点に固定せず、指の左右ドラッグに合わせた連続X座標で動く。自動前進・自動射撃。

- 走路幅の仮例：X=-3.6..+3.6、進路の中心X=-2.4,0,+2.4。進路境界は床の造形や発光線で表現する。
- プレイヤーのX座標は-1.1や+0.7のような中間位置にもできる。指を離しても前進する。
- 3分岐ゲートは左・中央・右に設置。必ず3つのゲートを設置する必要はなく、開放レーンもあり得る。
- 青ゲートは増加（×2、×5、+20）。赤ゲートは減少（−10、÷2）。色だけに頼らず符号とテキストで区別する。
- ゲートの境界で2つの効果が同時発火しないよう、当たり判定を排他的にする。
- ラン開始は必ず精子1体。ステージ/難易度/称号の影響なし。0体で道中敗北、ゴール100体以上で成功。

## 受け入れ検査

1. 390×844で左右・中央の3進路が一目で区別できる。
2. 自由X移動で任意のゲートへ移動できる。レーンスナップ禁止。
3. 青い進路では数が増え、赤い進路では減る。
4. 3択のうち任意のゲートを通過でき、境界誤作動がない。
5. 指を離した後も自動前進・自動射撃を継続する。
