# 競合比較・ゲームテンポ検証

競合候補：Count Masters、Mob Control、Last War広告等に登場するランナー型の操作演出。宣伝動画の演出は製品の実ゲームと一致しない場合もあるため、必ず区別する。

| 測定対象 | 測り方 |
|---|---|
| 操作理解の速さ | 初見ユーザーが移動できるまでの秒数 |
| 進行速度 | プレイ動画を秒単位で確認し、移動距離・分岐間隔を計測 |
| 1ランの長さ | ステージ1〜10で所要時間を実測 |
| 決断の頻度 | 青増員/赤減員、障害、敵の選択機会を数える |
| 攻撃の気持ちよさ | 射撃音・敵の反応・一斉撃破を初見ユーザーに評価してもらう |
| 成功/失敗の納得感 | ゴール分岐が人数と一致し、演出から理解できるか |

競合の正確な数値は未測定。Stage1 30〜40秒、Stage10 50〜60秒を暫定値とし、実測結果に応じて決定する。面数が少ないため、背景変更だけにせず固有の攻略判断を設ける。
