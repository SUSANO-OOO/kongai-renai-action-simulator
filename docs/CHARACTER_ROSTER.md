# 人物制作 — スタイライズCG寄りの2D立ち絵

本人回答は `docs/decisions/2026-11-01-owner-answers.md`。通常面の人物は全員架空の成人女性。高品質な2D立ち絵を初版の完成対象とする。全員を鑑賞できる3D化はゲーム完成後の任意候補で、初版や全素材査定の前提にしない。

表示するのは名前と見た目。国旗、国籍、文化背景紹介、人物の台詞、恋愛会話分岐は付けない。国の一覧を10ステージの看板にしない。顔立ち、肌の色、髪、体格、胸の大小、衣装、表情、姿勢の多様性は残す。身体や民族を難易度の根拠にしない。

何人かには人妻感のある、落ち着き・生活感・余裕・成熟した魅力を持たせる。若い顔の量産や同じ衣装の色替えにはしない。全員成人として年齢感を作り、ミニスカや胸元などの大人の衣装も共通の美術品質で仕上げる。ヌード・性行為を追加しない。

`data/characters.json` の名前、内部年齢、デザインの方向は制作側の一括提案。プロフィール文をゲームに長々と表示する用途ではない。完成美術は本人査定まで未承認。パイセンは別枠の男性で、最新の忠実なidentity-r2を基準にする。
