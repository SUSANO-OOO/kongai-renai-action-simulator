# Product Vision

婚外恋愛アクションシミュレーターは、成人向けの風刺コメディとして制作する、スマホ縦画面の3D群集ランナー＋オートシューティング。どこでも分かる直感的な左右フリーレーン移動と、予測可能な青赤ゲート選択、敵軍団との戦闘、1体→大群の成長に重点を置く。

**プラットフォーム：** 先にスマホブラウザ（iOS Safari・Android Chrome）、後からアプリ化を検討。

**ループ：** タイトル→ステージ選択（成人女性10人）→NORMAL/HARD→自動前進・増員・損耗→発光ゴール→SUCCESS/FAILED→コイン/EXP/スキン/称号→再挑戦。

**差別化：** 成人向けの冗談っぽい世界観、腐敗ゾンビ精子などの架空敵、成長の爽快感、11面の異なる攻略、ユニークな隠しパイセン面。生殖・着床は医学的な厳密な再現ではなくSF風の誇張表現。国籍や民族を解剖学的なステータスとして扱わない。

**品質ゲート：** 本格実装より先に、11ステージの全素材・女性10人＋パイセンのアート・3D/敵/UI/VFX/BGM/SEを制作、最低3周検査、ユーザー査定。仮素材を完成と称さない。
