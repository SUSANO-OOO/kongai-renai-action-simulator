# BGM・SEの制作方針

登場/クリア台詞、恋愛会話、分岐、人物の台詞ボイスは不要。性的快感の人物音声は制作対象外。非性的な掛け声を本人承認済みの代用品として無断追加しない。

青増員、赤減員、射撃、着弾、被弾、撃破、コイン、強化、ボス予告、UI操作、勝敗を区別できるゲーム音を作る。単調な試作トーンを完成扱いしない。

白金成功/紫吸引は同じ3Dゴールの衝突・人数確定・色・粒子・カメラと同期。重なる射撃と群集音の同時再生/音量を管理し、BGMと合わせ気持ちよさと判断しやすさを両立する。

独自制作か利用許諾を確認した音を使用。追加支出0円のため有料サービス/購入/従量課金は禁止。既存枠または確認済み無料手段だけ。編集元/配布形式/試聴/権利を査定へ含め、共通規格は `docs/ASSET_TECHNICAL_CONTRACT.md`。iPhone/Androidで初回操作・ミュート・復帰・スピーカー/イヤホンを検査する。
