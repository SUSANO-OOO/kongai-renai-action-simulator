# BGM・SEの制作方針

本人回答により、人物の登場/クリア台詞、恋愛会話、分岐、人物の台詞ボイスは作らない。性的な快感を表す声の制作は対応対象外と説明済み。人物の非性的な掛け声を本人が承認した代用品として勝手に追加しない。

ゲームの音響品質は必須。青増員、赤減員、自動射撃、着弾、被弾、撃破、コイン、強化、ボス予告、UI操作、勝利/敗北を区別できる音として作る。単調な試作トーンのまま完成扱いにしない。

白金成功と紫吸引失敗は同じ3Dゴールの衝突・人数確定・色変化・粒子・カメラと同期させる。重なる射撃と群集音は同時再生と音量を管理し、BGMを含め気持ちよさと判断のしやすさを両立させる。

ゲームプレイの音は独自制作または利用許諾を確認したもの。編集元、配布形式、試聴、ライセンスを全素材査定に含める。追加費用のサービス/購入はQ10で予算が承認されるまで使わない。iOS Safari/Android Chromeで初回ジェスチャ、ミュート、復帰、スピーカーとイヤホンを検証する。
