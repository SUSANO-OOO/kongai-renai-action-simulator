# サウンド・SE・BGMの方向性

ゲームの画面クオリティと同じ優先度で音響を制作する。使い捨ての汎用無料SEで埋めることはしない。

- 青ゲート：上昇ピッチ、軽快な増員SE。赤ゲート：下降音、危険を知らせる減員SE。
- 自動射撃：連続時にも不快にならない短く明瞭な音。着弾と撃破音は区別する。
- コイン：収集数に反応した心地よい音。
- ボス：出現の予兆、攻撃予告、命中、撃破の音。敵が多数でもゲームの状況が聞き取れる。
- ゴールSUCCESS：白金色の光の粒子＋勝利のジングル。FAILED：紫色の吸引渦＋低音と残響。
- タイトル／ステージ選択／ショップ／リザルトには独立したUI効果音を用意する。
- iOS Safariの自動再生制限、音量ミュート、モバイルスピーカー、ヘッドホンを検証する。
- 音源の所有権・生成履歴・ライセンスを台帳で確認し、素材として本人に査定依頼する。
