# 製品完成・公開の受け入れ条件

素材査定、ビルド成功、ゲーム完成、公開成功は別段階。本人判断以外の不足は制作側が改善・再検査する。

## 製品範囲
通常NORMAL10＋HARD10＋秘密HARD1、1体/3進路連続移動、青/赤/一時強化、敵/障害/射撃、コイン、4外見、経験値/称号、端末保存/復旧、設定/中断/再開、同一ゴールの成功失敗演出。順次解放・通常HARD初めから・秘密HARD・敗北回収コイン0・初版無料は回答済み。追加支出0円も確定し、これらを未回答へ戻さない。

## 証拠
- 0/1/99/100/巨大人数、ゲート二重発火、範囲外入力、終了後イベント、再試行初期化、報酬二重付与を実装に対して検査。
- 全21組み合わせで実操作のクリアルートと代表的失敗、解放を確認。机上探索や人数注入を本番完走としない。
- 3弱点の製品段階チェックと初見反応を観測。架空テスターを作らない。
- 複数縦長比率、安全領域、ブラウザバー、ポインタ取消、複数タッチ、中断復帰、読み込み失敗、WebGL非対応/コンテキスト喪失を確認。
- 実機/OS/ブラウザ/版/場面/計測法を記録。60fpsは目標と実測を分け、持続フレーム時間/メモリ/音切れ/発熱/長時間周回を検査。PCエミュレーションを実機と呼ばない。
- 音の初回操作/音量/ミュート保存/復帰/同時再生/ゴール同期、保存の不正/破損/旧版/容量/移行/一度だけの報酬確定を確認。無断で既存記録を破棄しない。
- 素材/フォント/肖像/作者名義/機密不在を確認。承認済みソースMITと素材別権利を守り、課金/解析/新ライセンスを無断追加しない。

## 公開
GitHub Pagesは候補で、現時点で有効化済みと扱わない。本人の公開許可、版/SHA、ビルド、実URL、初回ロード/キャッシュ更新、起動→1ラン→再挑戦、復旧版/手順を記録。公開後確認なしにrelease完了として閉じない。
`data/project-state.json` のreleaseChecksは証拠の索引。`npm run check:release` は不足検出であり、美術/面白さの自動合格器ではない。追加支出0円を公開時にも守る。
