## 自律進行
技術/制作手段/調整はCodexの裁量。低リスクPRは検査と根拠を揃えてmainへ統合可能。全素材承認、追加費用、初版公開など本人の判断は捏造しない。未回答の追加予算は新規料金を使う時だけ確認し、無料の独立作業を止めない。

| 段階 | 成果・次へ進む証拠 |
|---|---|
| 環境/方向性 | 実際の制作/描画/試聴/ブラウザ操作能力、代表画面と技術契約 |
| 全素材 | 11環境、人物2D、ユニット/敵/ボス、小物/モーション、UI、VFX、BGM/SEの編集元/配布用/プレビュー/権利 |
| 素材査定 | 3つの異なる観点の監査、全素材の本人承認と対象ダイジェスト |
| 本体統合 | 通常NORMAL10＋HARD10＋秘密HARD1、記録/報酬/保存/設定 |
| 製品QA | 実操作の完走/失敗、初見の面白さ、Android/iPhone実機、音/負荷/保存 |
| 公開 | 本人公開許可、版とSHA、実URLスモーク、更新/復旧手順 |

素材を検収する入力/カメラ/群集負荷/音の実験は承認前に行う。本編を完成させてから素材を一括差し替える工程には戻さない。素材承認に完成ゲームの全編QAを要求する循環も作らない。
