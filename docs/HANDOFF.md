## 引き渡し判定
`npm run check:budget` は費用方針、`npm run check:handoff` は全素材と本人査定の前提を検査。通常CI成功を引き渡し完了としない。`docs/ASSET_TECHNICAL_CONTRACT.md` と `data/stage-design-briefs.json` は制作基準で、完成素材ではない。
素材の入力/カメラ/負荷/音の検証は承認前に行う。本編完成後に素材を一括差し替える工程へ戻さず、逆に素材承認に完成製品全編QAを要求する循環も作らない。
