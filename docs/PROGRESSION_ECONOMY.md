# 進行・報酬・記録 — 本人回答反映

## 解放と難度
通常ステージは順番に解放。最初にステージ1を開き、解放済みステージではNORMAL/HARDを最初から選べる。NORMALクリアやNORMAL全制覇をHARDの前提にしない。次面の解放はどちらかの難度のクリアでよい共通進行を制作初期方針とする。通常10面のHARDクリアを個別に記録し、すべて揃うとパイセン面が開く。パイセン面はHARDのみ。

## コイン
道中で拾ったコインはラン中の仮残高。勝利した時だけ、回収分とクリア報酬を財布へ確定。負けたランで拾ったコインは持ち帰れず0。以前から持っていた財布の残高を減らす仕様ではない。再試行、リザルト再表示、保存復帰で二重付与しない。一意run IDで一度だけ結果を確定する。敗北時XPも初期案は0とし、未指定の調整値として記録する。

## 着せ替えと記録
初期外見＋追加3種類＝計4種類。すべて見た目だけを変え、性能差なし。`player-base` が初期、`player-skin-01..03` が追加。名称と価格は調整可能な提案。
個人ベストは面/難度ごとの最高生存数を中心に、回収コイン、撃破数、参考タイムを残す。自動前進が同一速度のときタイムだけを主な競技にしない。レベル/選択称号は達成要素で、永続攻撃強化や初期人数増加を与えない。オンラインランキングは初版範囲外。

## 保存
初版は端末内だけ。ログイン、サーバー、機種間同期は不要。破損/旧版/容量不足/無効なデータを検出し、無言の初期化や二重報酬を防ぐ。手動バックアップの追加は必須スコープではない。
