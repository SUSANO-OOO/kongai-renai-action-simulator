# 素材先行制作・ユーザー査定

正式ゲームの本格実装より**全素材の完成と明示査定を優先**。以前のプロジェクトのように仮モデルで全ゲームを組んでから一括差し替えする工程には戻さない。

## 必須素材

- 成人女性10人（統一画風・個別の髪型/体格/衣装/表情/立ち絵）と隠しパイセン。
- 味方精子の素体とスキン3種、ゾンビ精子、スライム、免疫系敵、各ボス。
- 11面の3D背景、肉壁、障害物、ゲート、コイン、ゴール。
- UI（タイトル、ステージ選択、HUD、ショップ、称号、設定、ポーズ、成功/失敗、解放画面）。
- 演出（増員/減員、攻撃、被弾、撃破、コイン、白金クリア/紫吸引）とBGM/SE。

## 制作順

1. 全体アートディレクション・技術的なモデル規約・UIのデザインシステム。
2. 必須素材を全件台帳登録。編集元/ゲーム用/プレビューを作成。
3. 最低3周の監査（仕様不足、見た目/統一感、形式/性能/ライセンス）。
4. ユーザーに一覧で査定依頼。**本人承認がない限り approved にしない**。
5. 正式承認後にゲーム本体を実装・通しプレイ・バランス調整。

コンペ画像はあくまで方向性の参考。ゲームにそのまま貼り付けたり「完成」として報告しない。アセット状態は not_started/in_progress/preview_ready/qa_passed/awaiting_user_review/approved/rework_required を厳密に使う。
