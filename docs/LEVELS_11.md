# 通常10面＋HARD専用パイセン面

通常10面は順番に解放。最初からHARDを選べるのは解放済み通常ステージについてで、全ステージが最初から開く意味ではない。NORMALとHARDの解放を二重管理せず、どちらかでクリアすれば次へという共通進行を制作側の初期方針にする。各面のHARDクリア記録は個別に保持する。

通常HARD10面の制覇でパイセンの11面を解放。秘密面はHARDのみ。通常NORMAL10＋通常HARD10＋秘密HARD1、計21の面/難度組み合わせを本編の検査範囲とする。

各面で異なる判断・地形・敵・見せ場を作る。入門、3方向判断、粘液、群れ、装甲、開閉、予告、変速、複合、総決算という以前の順序は制作の出発案であり、固定手法ではない。女性の国籍名や人種別の身体特性でコースを説明しない。

全モード1体開始、3進路の見た目＋連続移動、青増員/赤減員、同じ3Dゴールの100体条件を守る。時間・速度・数値は競合の観測と実プレイから調整し、未検証値を確定にしない。
