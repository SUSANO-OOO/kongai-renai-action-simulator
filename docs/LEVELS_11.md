# ステージ構成 — 通常10面＋隠し1面

通常は成人女性10人の異なるプロフィールと、各面固有の背景・地形・敵・見せ場を持つ。難しさは民族や解剖学的な差ではなくゲームデザイン上の敵・地形・イベント密度によって調整する。

| ステージ | 新しい体験 | 主要ギミック |
|---:|---|---|
| 1 | 基本操作の習得 | 1体スタート、青い増員ゲート |
| 2 | 3方向の判断 | 増員と安全のトレードオフ |
| 3 | 粘液区画 | 加減速・移動のしにくさ |
| 4 | ゾンビ精子の群れ | 自動射撃・回避 |
| 5 | 中ボス | 装甲ゾンビ精子 |
| 6 | 壁の開閉 | タイミングと進路の読み |
| 7 | 特殊ボス | 免疫系のモンスター |
| 8 | 速度変化 | 高速障害物と前兆表示 |
| 9 | 終盤複合 | 戦闘・ゲート・障害の組み合わせ |
| 10 | 最終決戦 | 複数ギミックと巨大ボス |
| 11 | SECRET / パイセン | 独自の架空SFコース |

NORMALをクリアしてからHARDへ挑む基本設計。全10面のHARDクリアでパイセン面を解放する。

### 難易度とテンポ
- 画面上は3レーン。左右には連続的な自由移動。
- どのステージ、難易度でも開始人数は1体。100体以上でクリア。
- HARDは敵HPを一律で増やすのではなく、レーン配置、ゲート値、障害物、危険予告、ボス行動の差で成立させる。
- 1面30〜40秒、10面50〜60秒は**競合の検証前の仮目標**。実測値とプレイヤーテストで調整する。
- 10面の単調さを防ぐため、各面に固有の判断と見せ場を最低1件入れる。
