# 11面の構成案

確定は「成人女性10人に対応する通常10面、NORMAL/HARD、通常HARD全制覇でパイセンの11面」。通常面の順序とHARD解放順はQ04、秘密面のテーマ/難度はQ05。旧資料の「NORMAL全制覇がHARDの必須条件」は本人の決定ではない。

| 面 | 差を付ける出発案 |
|---|---|
| 1 | 1体から増える基本操作 |
| 2 | 3進路の安全と報酬 |
| 3 | 粘液/減速 |
| 4 | ゾンビ軍団 |
| 5 | 装甲の敵と攻撃選択 |
| 6 | 開閉する障害 |
| 7 | 特殊敵の攻撃予告 |
| 8 | 速度/流れの変化 |
| 9 | 複合したリスク選択 |
| 10 | 全体の総決算 |
| 11 | パイセンの秘密面（固有仕様は未決定） |

これは固定の作り方ではなく、単調さを避ける配置案。Codexは面白さとコストに基づき再構成してよい。すべての面で初期1体、3進路に見える自由移動、青増員/赤減員、ゴール100体条件を維持する。ラン時間や予告時間は競合観測と実プレイで決め、未測定の秒数を固定条件にしない。民族や人体寸法を難易度の説明に使わない。
