# 開発費の追加支出は0円

本人決定は `docs/decisions/2026-11-01-zero-spend.md`、機械可読な金額・許可は `data/product-settings.json`。

既存利用枠で追加料金なしと分かる機能、無料のローカルツール、ライセンス確認済みの無料素材だけを使う。枠消費と追加課金を混同しない。プラグイン接続済み、APIキーあり、最初だけ無料という状態は支出許可ではない。

実行前に追加料金・従量超過・自動更新の可能性と利用権を確認。不明なら実行しない。有料API、クレジット購入、プラン変更、支払方法登録、自動チャージ、レンタルGPU、有料素材は禁止。枠不足で品質を無断で落として完了扱いにもせず、無料代替と残件を示す。予算を通常の再質問事項に戻さない。

## このリポジトリの検査
通常CIはpublicの標準ubuntu-latestだけ、読み取り権限・時間上限付き。定期実行、large runner、自己契約クラウド、不要なキャッシュや成果物の自動蓄積を追加しない。非公開化された場合は停止し、無料条件を確認し直す。既存の暗号化履歴復旧artifactは別処理の証拠で、日常CIの保存先にはしない。

GitHub公式で公開repoの標準runner計算が無料であることを確認したが、アカウント全体のストレージや他サービスの請求が0円であることをこの文書は保証しない。請求画面を確認せず課金設定も変更済みと報告しない。
参照（2026-11-01確認）：https://docs.github.com/en/billing/concepts/product-billing/github-actions

`npm run check:budget` は方針・CI設定・現行文書の逆戻りを検出する静的検査。外部アカウントの課金を遮断するシステムではない。
