# ゲームフローの検収

## 素材制作中に検査すること
3進路のカメラ、連続的な横移動の検証場、青赤の読み分け、群集の見え方、同一3Dゴールの白金/紫のプレビュー、音の同期、数量0/99/100等の境界仕様。現在の `scripts/lib/run-contract.mjs` は数値の実行可能な仕様であり、製品の戦闘エンジンではない。

## 本体統合後に検査すること
開始→増員→射撃/回避/一時強化→損耗→ゴール→報酬→再挑戦を実際の入力で通す。イベントは一度だけ適用、終了後に増員/損失/報酬が追加されない。リトライで1体とラン内強化初期値へ戻る。
通常10面のNORMAL/HARDの完走可能性、0体の途中敗北、99体失敗と100体成功、隠し面の解放を版付き証拠で残す。敵を無敵化したテスト、人数注入、旧試作の机上経路探索は製品の実操作完走ではない。

素材の承認に本体の完走テストを要求せず、逆に本体完了を素材プレビューだけで判定しない。詳細は `docs/RELEASE_ACCEPTANCE.md`。
