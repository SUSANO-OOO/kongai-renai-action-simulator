# 3弱点の実装受け入れ基準

1. **単調さ対策**：通常10面すべてに異なる判断/危険予告/ギミックが存在。HARDはHP倍率だけでなく敵・障害・ゲート配置で違いがあること。競合の進行テンポと比較し、初見テストを実施する。
2. **素材品質対策**：必須素材台帳全件に編集元/ゲーム用形式/プレビュー/権利記録。女性10人とパイセンの整合性、背景/3D/音/UIの最低3周監査、本人の明示承認。未承認は完成扱いしない。
3. **達成感対策**：1体開始→倍率ゲートで増員→損耗→100体以上でクリア。スコア・軍団の見た目・SEが一致。同じ3Dゴールに対して白金SUCCESS/紫FAILEDを演出する。

## 検収物
- 各面NORMAL/HARDの再現可能なプレイ記録と生存数
- 青ゲート増員/赤減員と3方向自由移動の回帰テスト
- ゲーム内実演の成功/失敗映像、音響試聴、端末性能ログ
- キャラクター11人の一覧プレビューと権利記録
- 最低3回の監査ログ、修正前後の比較、ユーザー承認結果

数値は競合の実測後に確定。コンペSVGは参考構図であり、完成3Dの検証代わりにはならない。
