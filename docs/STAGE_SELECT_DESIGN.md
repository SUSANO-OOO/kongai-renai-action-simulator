# ステージ選択UI — 人物を中央に大きく

スタイライズされたCG寄りの高品質2D立ち絵を中央に表示し、左右スワイプで人物/ステージを切り替える。通常10面は順次解放。名前と見た目で魅力を伝え、国旗・国籍ラベル・文化紹介・台詞は入れない。

上：ステージ番号、キャラ名、クリア記録、財布。
中央：立ち絵、統一感のある背景、次/前のカードへの導線。
下：NORMAL/HARD選択、開始、戻る。解放済みの通常面ではHARDが最初から有効。未解放の次面そのものはロックする。
秘密面：通常HARD10面制覇でパイセンを解放。HARD固定、NORMALボタンを有効にしない。

9:16および390×844等の縦長画角に自然に対応し、safe-area/文字サイズ/親指の届く範囲を検査。国籍が残る旧WebPは不採用ラフとして隔離し、そのまま製品UIに貼り付けない。初期込み計4スキンは別のコレクション画面に接続する。
