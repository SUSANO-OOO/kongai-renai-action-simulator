# ステージ選択UI（スマホ9:16）

選択中の成人女性を**画面中央で大きく表示**し、左右スワイプで切り替えられるレイアウトにする。10人それぞれの魅力が1秒で分かる衣装・表情・姿勢と、統一されたアートディレクションを両立する。

上部：STAGE 01/10、名前・国/文化モチーフ、コイン、クリア状況。
中央：選択中の立ち絵。背景は該当ステージの3Dアートの雰囲気を反映。
下部：NORMAL/HARD切替、STARTボタン、BACK、解放状態。
SECRET：全HARDクリアまではパイセンの影カードとして非公開表示。

実装では固定画像ではなく、テキスト・タップ領域・フォーカスを編集可能なUIとして作成。360×780/390×844/430×932、各ブラウザの安全領域・文字の折返しを検証する。最初のAIコラージュ画像をそのまま貼り付けない。
