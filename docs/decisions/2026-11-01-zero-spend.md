# 追加支出0円・引き渡し前準備の本人指示

2026-11-01、Q回答反映後の追加指示。本人は既存枠と無料手段だけという条件を「それは絶対です」と明示し、Codexへ受け渡す前の作業が未完了なら実施するよう依頼した。

追加支出の上限は0円。既に契約済みの利用枠と、料金が発生しないと確認できた手段だけを使う。有料API、素材購入、従量超過、クレジット追加、自動チャージ、新規契約、有料へ移行する試用は使わない。枠が尽きても課金手段へ切り替えない。無料代替を検討し、不可能なら影響する作業だけを未完了として報告する。予算相談を通常工程として再度持ち出さない。

以前のQ10「未回答／必要時に予算確認」は本指示で上書き。機械可読な現行方針は data/product-settings.json の paidExternalResources。これは開発費の制約であり、ゲームの配布価格・将来の広告希望とは別。静的検査は外部の支払口座へ上限を設定する機能ではない。

## 受け渡し
仕様書の整備、完成素材の制作・動作確認、本人の一括査定、Codexでの本編統合は別工程。全素材を先に揃える指示を、文書だけ完成した状態や仮素材で完了扱いにしない。素材検証用ビューアは先行可能だが、全素材未承認のまま本格キャンペーンを引き渡さない。
