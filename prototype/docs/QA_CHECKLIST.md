# 品質監査チェックリスト（3周＋回帰）

## 1周目：遊び
- [ ] ドラッグは絶対座標へワープせず、相対移動。3レーンに吸着しない
- [ ] Xの端は越えない。障害を跨ぐ際に当たり判定が一致
- [ ] 10通常ステージ+隠し1ステージに新しい仕掛けがあり、見た目だけの違いではない。HARDは単なる敵HP差でない
- [ ] 増殖ゲートの数値が正しい、二重適用しない
- [ ] 攻撃は自動かつ分かりやすい。敵群・障害・ボスの判定が正しい
- [ ] 全モード・全ステージ初期1体。0体で途中失敗、ゴール1〜99体で失敗、100体以上でクリア。報酬の二重発火なし
- [ ] 不可避の詰みを生むギミックがない

## 2周目：画面と音
- [ ] スマホ画面に映した際の精子・ゲート・弾・敵・壁が区別できる
- [ ] 全11面の照明・材質・3Dモデル・背景・演出が意味をもって違う。完成素材の本人査定と承認を確認
- [ ] 精子・敵・各ボスに編集可能な3DソースとGLBがある
- [ ] グロー/点滅/安易な素材と文字が浮いていない
- [ ] HUDがDynamic Island・ノッチ・ホームバーに被らない
- [ ] ボスの攻撃予兆が遠景から分かる
- [ ] BGM・SFX・消音・復帰が正常で音声が途切れない

## 3周目：性能と回帰
- [ ] 実戦では巨大軍団数をGPUインスタンシングで上限付き表示
- [ ] 連続プレイ・リトライ100回でメモリリークしない
- [ ] 低スペックは30fps安定、高性能は60fpsを目指す
- [ ] 横長端末や向き変更でもクラッシュせず縦画面へ誘導できる
- [ ] 保存破損から安全に復帰、既存記録を不要に消さない
- [ ] 公開repoに鍵・連絡先・実名・個人データがない
- [ ] `npm run build` `npm run test` `npm run lint`（追加後）が通る

## 報告フォーマット

ステージ | FPS（実機/エミュレータ） | 視認性 | 操作感 | バグ | 改善済み/残件 | 動画/キャプチャ

テスト未実施の場合は、どのチェックが未実施か正直に示す。推定と実測を混同しない。
