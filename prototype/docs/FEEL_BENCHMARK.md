# 競合作品の操作テンポ：調査と試作計測

## 参考作品と判明している点

- Count Masters: Crowd Runner 3D（Freeplay LLC）—公式App Store説明ではスワイプ群体操作/倍率ゲート/敵との衝突/コイン収集/ボス戦。https://apps.apple.com/us/app/count-masters-crowd-runner-3d/id1568245971
- Last War: Survival Game 前線突破 — 手前の部隊を左右操作し、敵・障害物・人数増員パネルを処理する短編モード。https://game8.jp/lastwar-survival/641694
- App StoreのCount Mastersのユーザーレビューには『1ラウンド15〜25秒』という感想もあるが、特定ユーザーの観察であり、全ステージの公式公表値ではない。速度の厳密値は **現状未測定**。

- **既存試作の距離/速度の机上計算はStage 1約40秒〜Stage 10約70秒**。前表は測定ではなく許容レンジの仮説。HARDのタイムは敵配置などが未実装なので未設定。
- ステージが長くなっても中身をスカスカにしない。目標は「動く→2〜5秒で最初の気持ちいい選択→7〜10秒ごとに小さな判断/報酬→短いクライマックス」。
- **ユーザー指定**：全モード初期精子は1体で、100体以上生存してゴールする。倍率の配置は走行テンポと勝利可能性の両方を満たす。
- 速度は最初の3〜5秒に最高速へ上げない。序盤80〜90%→中盤100%→終盤105〜115%を仮の演出案とする。画面上の障害予告表示から接触まで1.5秒以上を通常目標、HARDでも最低1.25秒以上で検証。瞬間的な理不尽死は不可。
- 目標ラン時間は新しい素材とカメラを入れた上で**再計測**する。単純にマップ距離だけ変えて時間が合えば完成ではない。

## 測定手順（Codex必須）

1. 参考作品の使用バージョン/端末/OSを記録し、少なくとも3ステージずつ操作動画で記録。
2. 各動画の「操作可能→最初のゲート→初戦闘→初コイン→大きな波→ゴール」までを秒単位で採寸。
3. 本作品の同じ地点を収録し、視認可能距離、画面横移動の遅延、単位時間あたりの判断回数、敵処理の爽快感を比較。
4. 30/60FPS環境で入力遅延、詰まりやすいゲートの視認時間を確認。遅ければ間延びを減らし、速すぎれば予告時間を増やす。
5. 3回以上チューニングして差分記録・比較動画を提出。根拠が得られるまで「競合と同じ速度」を達成したと書かない。
