# ステージ選択画面：プレミアムゲーム並みのUI仕様

## 画面設計

縦390×844基準。タイトル画面から「女性を選択」に入る。10人の成人女性を、**横スワイプの大型キャラクターカード**で表示。カード1枚を中心に、隣のカードを端だけ見せて次の人物がいることを示す。右上にはコイン・ユーザーレベル/称号、左上に戻る。下部にステージ名、個別のプレイ特徴、クリア印、NORMAL/HARD切替（HARD未解放なら説明付き錠）、大きな出撃ボタン。

## 人物の見せ方

- 人物の立ち絵/カードはシネマティックな横顔・全身を統一トリミング。露出だけを強調せず、色気は表情・仕草・衣服・光の立体感で表現。
- 10人を1画面の豆粒グリッドに押し込まない。10人の顔の魅力とステージ世界観の両方が分かるヒーローカード型のUX。下に細い10個の進捗インジケーター。
- 画面奥には選択したステージの低負荷3D背景を暗めに表示、前景の人物立ち絵は強い可読性を優先。人物画とGLBの双方に一貫した色・光のルール。
- カードをタップすると人物紹介・使用ギミック・ベスト記録/コイン報酬・選択中の難易度・適切な警告が展開。カード間切替は200〜250ms程度、過度なパララックス禁止。

## モードと解放

- `NORMAL`: ステージ1から順に開放。すべてのNORMALをクリアするとHARD切替解禁。
- `HARD`: 1〜10全てを再攻略。単なる敵HP水増しでなく、地形/危険の予告と選択の密度を強める。解放は各ステージの難易度タブとクリアバッジで可視化。
- `SECRET`: HARD10面すべてクリアすると、**11番目のカード「パイセン」**が現れる。解放前のカードは伏せられた「???」のシルエットのみ。HARD全制覇後は専用登場アニメとSEを流す。
- 1回のクリアと全制覇の評価を分け、ボス達成印や最速タイムを提示。属性（性別/出身地）を身体能力の性能として表示しない。

## 高品質の受入判定

1. iPhone Dynamic Island/ホームバー、360/390/430幅で表示が切れない。
2. 親指で1つの操作ができる。最小タップ領域44pt相当。
3. キャラクター全員が同じアートディレクションで、顔・衣装・背景色の個性が明確。安価なAI風人物立ち絵に見えない。
4. 5秒以内に「誰を選ぶ・どの難易度・開始」が分かる。長い説明の押しつけ禁止。
5. BGM、ホバー相当の選択SE、解放演出、ボタン押下時のハプティクスの組み合わせを審査。
