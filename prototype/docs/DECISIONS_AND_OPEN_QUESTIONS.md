# 決定事項・仮決定・確認が必要な点

## ユーザーが決めた事項（勝手に変更しない）

- タイトル『婚外恋愛アクションシミュレーター』、他のゲームとは完全に独立した新規リポジトリ。
- 先に**スマホブラウザ版**。縦画面、リアルタイム3D風（実際には3Dを使う）。3レーンに見える自由横ドラッグ、自動前進/射撃。
- 敵はゾンビ化した残留精子、マンカスのデフォルメ、その他の障害。掛け算/足し算や一時強化ゲート、コイン。
- **スタート時の味方精子は必ず1体**。到着時100体以上で勝利。0体で敗北。人が実際に操作するゲームの爽快感を優先。
- 通常10ステージは異なる架空の成人女性10人。女性の立ち絵は統一画風で、色気があり、体型・衣装・胸のサイズなどは多様。ステージ選択UIで中央に大きく表示。
- NORMAL/HARDの2難度。10面HARD全制覇で、男性パイセンを題材とした隠し11面を解放。
- コインで外見を変える初期3スキン、XP/15ランク/称号選択。レベル/スキン/称号で恒久的に攻略が簡単になる効果なし。
- **全素材（3D・背景・UI・音・VFX）を先に制作し、本人の査定承認後に本格ゲーム制作**。3周以上の監査と修正。
- パブリックGitHubは許容。公開前の個人情報/ライセンス確認が必要。

## 制作を進めるための仮決定（レビューで変更可能）

- 技術: Vite＋TypeScript＋Three.js、390×844 CSS px基準、ブラウザWebGL、GitHub Pages候補。
- 解放順: NORMALは1〜10を順番、NORMAL10面全クリア後HARDが解放、HARD10面全クリア後SECRET解放。ユーザーが確定したのは最後のSECRET解放条件で、**HARDの解放条件は制作側仮案**。
- SECRETは生殖現象を医学的に表す設定ではなく、パイセンの独立したSFコース。
- 1ランのプロトタイプ計算値40〜70秒を基準に、競合の実測を採って30〜70秒程度の範囲で再調整。
- 成功演出の3段階: 100+, 1,000+, 10,000+（ゲーム上の演出・スコアのみ）。
- 成人女性のキャラ設定、名前、年齢（全員25歳以上で案を作成）、衣装、ステージ題名、コイン価格、称号名はすべて初稿。本人査定までは確定しない。
- 末尾のボスはStage 5/7/10。敵の正確な強さ/配置/時間はプレイテスト後に決定。
- 11面のNORMAL/HARD表記は本編10面と異なる隠し面1種類を第一候補。HARD勝利で解放し、隠し面そのものの2難度化は未確定。
- 収益化、広告、ゲーム内課金、ランキング等は初期版では実装しない。

## 発注の直前に合意したい最小の論点（決定がなくても暫定案で設計を進められる）

1. 成人女性の**立ち絵をゲーム内の3D人物として実際に表示する場面**を作るか、それともステージ選択中心にするか。現アセット台帳は3D人物モデルも要求している。
2. HARD解放を『NORMAL10面全制覇』とするか、各面のNORMALクリア後に個別開放とするか。
3. 10人の成人女性の名前/国籍/スタイルを初稿で査定する方法（10人一括か3人代表試作→方向承認→10人一括）。最終的な全素材承認は一括のまま。
4. SECRETの勝敗条件（現仮仕様は1体開始・100体ゴール、架空の端末到達）と演出。
5. クリア後の継続動機（コイン/称号/ベスト記録以外の追加チャレンジを入れるか）。まずはリトライとHARDの設計を優先。

## 医学的・倫理的な扱い

異なる文化的背景や肌色のキャラクターを設計する一方、人種/民族ごとに生殖器の長さや能力が決まる設定は採用しない。短い/長いステージ、敵/地形の違いはすべて架空のゲームデザインとして割り当てる。原則として架空の成人キャラクターを使用する。
