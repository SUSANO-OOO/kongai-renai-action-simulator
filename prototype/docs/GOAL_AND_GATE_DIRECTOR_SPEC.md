# 倍率ゲート・ゴール演出のディレクション仕様

更新: 2026-11-01 / ステータス: 試作コードの赤ゲートとデータへ反映済み、アートは査定待ち

## 1. 固定仕様

- すべての通常ステージ、すべての難易度で味方精子は**1体からスタート**。
- スマホ縦型9:16。コースは三本に見えてもX座標が滑らかに動くフリーレーン。自動前進・自動射撃。
- 青いゲートは増加専用。表記例 `×5`, `+20`。
- 赤いゲートは減少専用。表記例 `−5`, `÷2`。
- 同時に並ぶゲートには利得・損失の選択があり、赤い経路しか存在しない理不尽な詰みは避ける。少なくとも理論上100体に到達できるルートを保証。
- `×N` は現在人数に対する整数乗算、`+N` は人数加算、`−N` は0まで減算、`÷N` は小数切り捨て（1未満を0）を暫定採用。赤ゲートの値は表示と実計算を一致させる。
- 難易度NORMAL/HARDの差は敵密度・攻撃予告・ゲート配置などでつけ、理不尽な不可避失敗を避ける。

## 2. 同じゴールオブジェクトの二分岐

**衝突した瞬間に生存数を固定し、判定を一回だけ実行。** エリア突入前に結果を決定しない。

| 到達時の生存数 | 判定 | 表現 | 効果音 |
|---|---|---|---|
| 0体 | コース途中で敗北 | 味方が消滅した位置でゲームオーバー | 短い低音衝撃とフェード |
| 1〜99体 | ゴール到達・失敗 | 白金色ゲートが急速に紫へ反転、渦を開き、残存精子が一斉に吸い込まれる | 吸引・歪み・低音バースト・短い余韻 |
| 100体以上 | ゴール到達・成功 | 白金色の発光、精子軍団が光に包まれ、粒子が上昇。明瞭なCLEAR表示 | 上昇スイープ・明るい衝撃・勝利ジングル |

生殖路をイメージしたファンタジー生体SF空間として統一。実在の子宮口や子宮の厳密な解剖学的図解ではない。実際の受精・着床の科学的説明と混同しない。

## 3. 映像・音響の完成条件

- 同じゴールモデルで成功/失敗の材質・シェーダー・エミッターを切り替える。
- 画面全体を白飛びさせっぱなしにせず、精子群・判定・リザルトが読めるよう露光と発光を制御。
- 低性能端末では粒子数・ポストエフェクトを落とすが、成否を示す形・色・SEの区別は維持。
- ミュート・減音・振動OFFを設定に用意。サウンドの音量・音色・衝突感の審査を別途行う。
- 細かなカメラ揺れを演出に使えるが、操作不能感や画面酔いを避ける。
- UIに `100体以上でクリア` を表示し、99/100境界の自動テスト、難易度両モード、復帰、ポーズ、リトライの総合テストを必須にする。

## 4. コンペ画像の採用ルール

`concept-art/` の切り出し画像には意図しない文字や人物とゴールの混在がある。**構図・色・雰囲気の参考に限り使用し、正式な完成画面を示すものとは扱わない。** 特に `09_clear_screen.png` と `10_failed_screen.png` の人の顔・身体や文章は、ゲーム内の最終3Dゴール画面にコピーしてはいけない。ゴールは発光ゲートの正面と、精子の数がわかるHUDが主役。
