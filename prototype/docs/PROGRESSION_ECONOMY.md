# コイン・スキン・ユーザーレベル・称号

## コイン

敵を倒した際、低確率でコインをドロップ。ボスはコイン確定。コース上にも手作りでコイン配置を可能とする。財布の通貨は普通の金貨のモチーフでよく、ゲームらしいのに世界観になじむ**渋い真鍮コイン**。数字は画面端に小さく表示、回収した時だけ短い光・SE・数字ポップ。抽選はseed付きで同一条件の公平性を確保。

## 着せ替え：初期3種類

- `オリジナル精子`: デフォルト無料、青緑と乳白。
- `スパルタ精子`: 120コイン、紫の装甲輪と戦闘感のある意匠。
- `ナイトメア精子`: 450コイン、漆黒と金、尾に稲妻状の細い紋様。

外観（モデル/テクスチャ/泳ぎエフェクト/カードUI）を区別し、色の塗り替えだけで新しいスキン扱いにしない。**全スキンのHP・攻撃・速度・射程などは同一**。コインでゲーム難度を下げない。

## ユーザーレベルと称号

仮の固定ユーザー名は「精子くん」（**名称は本人査定待ち**）。レベルに応じて15段階の称号が順次開放され、プロフィールで好きな称号を選ぶ。選ぶことでユーザーネーム表示が変化するが、能力値は変わらない。XPはクリアで獲得、リプレイは減額するが詰まない。

1. まだ名もなき一匹 / 2. 尾びれの新兵 / 3. 逆境スイマー / 4. 倍率の開拓者 / 5. サバイバル精子 / 6. スパルタ精子 / 7. 戦場の泳ぎ手 / 8. 不屈の残存者 / 9. 深紅の突破者 / 10. ナイトメア精子 / 11. 粘膜の征服者 / 12. 伝説の増殖者 / 13. 無限群体の指揮官 / 14. 絶対生存者 / 15. ラスト・ランナー

秘匿称号「パイセンに認められし者」はステージ11の初クリアで獲得。上記15ランクに加えて選択可能とする。
