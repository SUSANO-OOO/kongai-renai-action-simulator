# 04 — アートディレクション / 3Dモデリング / VFX

> **2026-11-01改訂優先ルール:** `AGENTS.md` と `docs/ART_FIRST_APPROVAL.md` が最優先です。現行コードは未査定の試作であり、全アート/UI/音響の制作・制作者査定が終わるまで本格実装に進めません。通常10面＋HARD10面＋隠し1面。詳細は `data/characters.json`, `data/progression.json`, `data/secret-stage.json` を参照。


## 作品固有の絵作り

**キーワード:** 有機的な生体SF、薄い膜の透過、湿った質感、コミカルなのに妙に本格的、群体のうねり。

参考の広告ゲームの**遊びやすさ**を踏襲する。ただし、汎用の棒人間・ベタ塗りのランナー床・素材を貼っただけのUIは使わない。現実の解剖を正確に再現する作品ではなく、やや不穏な器官内SFを独自に創作する。

### 見た目の優先順位

1. 精子だと一目で認識できる独自形状（オタマジャクシ状の頭部＋鞭毛）、大群で映えるシルエット。
2. ゲート倍率と危険物が小さい画面でも0.5秒で判読できる。
3. 床の3レーン境界が自然な生体模様として分かる。
4. カメラに奥行きがあり、手前の敵・遠景の障害に距離感がある。
5. ステージごとに別の環境アイデンティティがある。

## パフォーマンスを前提にした制作

- 近距離リーダー：~1,500〜3,500 tris（推奨目標）。群体：1体80〜300 trisの簡略LOD。
- 量産ユニットは `InstancedMesh` または同等GPUインスタンス、個別の独立Mesh量産禁止。
- 実戦の可視ユニットは端末性能別に約150/350/650を目安として調整。戦力値上限とは無関係。
- 可視ユニットの鞭毛は低LOD時、頂点シェーダーの波打ち・一括変形を検討。
- 1画面に常時強いBloomや高コストポスト処理を入れない。色調はPBRマテリアルと照明が主体。
- モバイル向け1K〜2Kのテクスチャアトラスを優先。透明材は重なりとオーバードローに注意。
- Blender等の元データは `assets/source/`、GLBは `public/models/`、プログラム生成素材は出所を明記。

## マテリアル・色・ライティング

- プレイヤー：柔らかな青緑・乳白、光沢は中程度、マットな陰影の中に半透明膜のアクセント。
- ライバル：コーラルレッド〜深紫、被弾時だけ高輝度のピンクを使う。
- 回廊：暗紅、肉色、青紫の間でステージ差を出す。床は湿潤感、壁は柔らかな散乱感。
- 安全・増員：青緑。強化：明るい琥珀。損失：濃い朱色。危険：橙〜赤。色だけで判断させず形とラベルを変える。
- 主照明：暗めの環境光 + 側面の赤い面光源風 + 危険物を明示する局所ライト。白飛びを避ける。

## 画面効果・フィードバック

- ゲート通過：フレームが割れる、乗算値が一瞬だけ大きくなる、軍団の密度が増す。
- 攻撃：精子の頭部から短い光弾。「射精」等の実写的表現ではなく、架空のSF射撃。
- 被弾：短いヒットストップ／軽微な揺れ／損失数ポップ。画面全体の強い点滅は禁止。
- ゲームオーバー：強い赤フラッシュより残存軍団の沈黙を使う。
- Boss：前兆のリングと短いテレグラフ。視認性が最優先。

## モデル納品の判定

完成物に必要なもの: `.blend`等の編集元、GLB、プレビュー画像、命名規約、アニメーション名、各LOD、使用テクスチャ、ポリゴン数。**生成された3Dっぽい画像を貼り付けるだけでは3Dモデル完成とみなさない。**
