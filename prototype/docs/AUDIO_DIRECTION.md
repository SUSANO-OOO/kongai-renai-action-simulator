# 音響：チープさのない短編アーケードサウンド

## 方針

音は「軽快な勢い・生体SFの粘性・敵撃破の重さ」の3要素。量産効果音の貼り付けや安い効果音ジェネレーターの単音のみで『完成』扱いしない。短いアーケード体験に合わせてBGMが操作を邪魔せず、戦闘中もSEの輪郭が聞こえるように設計。

- 各ステージ：固有カラー/リズムと共通主題を持つループ。メニューBGM、隠しステージ専用曲、ボス戦用の短いレイヤー。
- ゲート：×20などはピッチと倍音が上がる増殖音。マイナスは低い脱力音、強化は短い金属音。
- 射撃：単発ごとに同一音をコピペしない。短い複数のバリエーション、同時発射数はミックス処理。
- ゾンビ精子：濡れた破裂音に低い空気感を混ぜるが、過剰な生々しさを抑えてコミカルな手応え。
- コイン：硬貨の丸い金属音、ピッチは連続拾得時だけ変化。
- パイセン：特別な登場ジングルとコメディ調の短い決め音。既存作品の音をそのまま持ち込まず原曲使用権を確認。
- ステージ選択：人物カードをめくる軽やかなSE、HARD解放は独自ジングル、15称号の昇格には気持ちのよい余韻。

## 制作・検査

- 元データ WAV 48kHz 24bit、配信用Ogg/ブラウザ互換フォールバックを用意。スマホはユーザー操作からAudioContext開始。
- バス分離：Master / Music / SFX / UI。設定画面で独立音量と消音。連射・爆発の重複再生によるクリップと音抜けは禁止。
- ラウドネス・最大ピークを測定し、無音/突然の爆音/隙間/ループ時クリック/音声の途切れを通し確認。
- オリジナル音源または商用利用許諾・クレジットが明確な音源のみ採用。すべて素材台帳へ登録。
