# Codex開発ロードマップ（アセット先行ルール版）

## Phase 0 — 状況監査 / 新規独立リポジトリ

- [ ] 新規GitHub `SUSANO-OOO/kongai-renai-action-simulator` を作成（既存Zombieeeへは書込禁止）。現時点で接続GitHubツールにはリポジトリ作成APIがないため未実施。
- [ ] 既存プロトタイプを棚卸し、コードと完成素材を区別。旧仕様の矛盾（10面のみ/永久戦闘強化など）は最新版で置き換え。
- [ ] `data/asset-manifest.json` をIssueへ展開し必要素材の担当/進捗/品質検査を管理。

## Phase 1 — デザインと素材を**先にすべて仕上げる**

- [ ] 作品ロゴとデザインシステム、10人の成人女性＋パイセンの立ち絵/カード、同一性チェック。
- [ ] 3D精子（初期3スキン）、腐敗ゾンビ精子、マンカス型スライム、免疫敵、ボス、その他全ユニットとアニメ/LODの編集元とGLB。
- [ ] 通常10ステージの個別背景/回廊/ボス空間と、隠しパイセン用の別背景/ギミック。
- [ ] 全ゲート、コイン、VFX、UI全14画面（縦360/390/430幅）、フォントとアイコン。
- [ ] BGM/SE/ジングルとミキシング元・商用利用権利・配信用変換。
- [ ] データ台帳・サムネ・比較シート・動画・技術検査を揃えて3周監査し、問題を直す。
- [ ] **本人査定依頼：承認が取れるまで次フェーズ開始禁止。**

## Phase 2 — 初めてゲーム体験を完成させる

- [ ] 素材承認後のみ、承認済みアセットでStage 1の縦切り。スワイプ、3レーンの見た目とフリーX、ゲート、自動射撃、100体ゴール、コイン、UIを通す。
- [ ] 対照ゲームとスピードを3回以上比較。正確な秒数は動画と実機で測定し、最初の増殖/判断までの時間、空走時間、手触りを調整する。
- [ ] Stage 2〜10のNORMAL/HARD、スタート人物選択、独立したボス/ギミック、レベル/称号、3スキンの保存。
- [ ] NORMAL10面完走→HARD解放→HARD10面完走→パイセン11面の解放→ボーナスクリアまで通す。

## Phase 3 — 品質監査 / リリース

- [ ] 11面×対応モードを成功/失敗/再戦で全通し、端末別FPS・操作・音・画面安全域・セーブ復帰を検査。
- [ ] 性能/ゲームバランス/アートUI音響の3周監査と修正後の再検査。
- [ ] 全素材出典、肖像、音源、個人情報、パブリック公開時の許諾を最終確認。

### コーデックスに対する禁止

Stage 1を先に完成させてからモデルを量産する旧フローは禁止。「仮モデルがあるから先にゲームを作る」も不可。**初めに素材総仕上げと査定。**
