# 既存プロトタイプコードの参照用保存

このフォルダは改訂版ローカルZIPに含まれていた初期試作コードの参照用であり、**完成ゲームではありません**。現在のルートアプリはコンペ画像のレビュー画面です。

以前のV3初期試作から元のテキストファイル56点を移行済み。`src/`、`data/`、`scripts/`、設定ファイルはここで個別参照できます。素材制作を優先する正式ルールはルートの `AGENTS.md` です。

`cd prototype && npm install && npm test && npm run dev` を試作コードの実行コマンドとして使用できます。依存環境と実機での動作検証は別途必要です。
